# Runbook: потеря Pixel или основного MacBook (план 17.4)

1. Отключите или удалите потерянное устройство в Tailscale admin console.
2. Удалите его из grants/ACL tailnet policy. Проверьте, что нет другого широкого правила: разрешения
   складываются.
3. На каждом хосте явно завершите активные сессии и остановите доступ (`direct-server = "N"`,
   перезапуск), если сессия могла быть открыта. Изменение ACL само по себе не обрывает уже
   установленную сессию.
4. Смените пароли Remote Hub всех хостов, которые были сохранены на устройстве.
5. Включите доступ обратно и проверьте подключение с оставшегося контроллера.

Не выполняйте `tailscale logout` на хостах и не сбрасывайте весь tailnet policy.
